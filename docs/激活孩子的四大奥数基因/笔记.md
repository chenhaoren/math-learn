## 大脑发育的核心原理

1. **激活而非灌输**。大脑的发育不是灌输，而在于激活。激活的三大通路：听觉、视觉和触觉。
2. **脑区分工与整合**。初级功能由特定脑区来实现（如听见声音、看见东西、触摸事物）；高级功能则连接不同脑区，对信息进行综合加工，形成数感、空间感等更深层的认知。
3. **神经元的连接**。婴儿出生时已拥有约860亿个神经元，但多数相互独立，仅少数维持生存的神经元彼此联通。
4. **窗口期**。0-3岁是神经元连接布线高峰期，外界刺激促使相关脑区的神经元联结，传递信号。

> **由此得出儿童大脑发育的三大规律：**
>
> 1. 大脑发育从激活感觉功能区的神经元通路起步。
> 2. 听觉、视觉和触觉是大脑发育的核心通路。
> 3. 大脑绝大部分通路在3岁以内形成，但4-7岁的广泛连接、巩固强化与整体统合同样关键。**用进废退**——长期不用的通路会逐渐退化。

## 关于大脑潜能的家庭布局

### 听觉环境
三不原则：不加快语速、不提高音量、不重复用语。

创造一个没有压力的听觉环境，不要让孩子感觉在压迫。比如，一句话重复多次就会让孩子感觉压迫，对同一件事情，可以不同表达，不同视角的表达。

### 视觉环境

**原则：减量 + 有意识地布置文字信息。**

1. **玩具精简**。孩子视线中不应散落太多玩具，这会干扰注意力。正确做法：只留少量在外面，其余藏起来，每两周轮换一批。有利于培养孩子的深度专注。

2. **大字墙贴**。选择笔画4以内的100个汉字，用A4纸打印（字号≥600pt），黑色/红色/蓝色/绿色各25个，贴满一面与孩子视线平齐的墙。不主动教，孩子在日常中主动停下来看的时候，就是无压力的主动学习。这样能建立对文字的亲切感。

### 触觉环境

**触觉 = 皮肤接触 + 操作体验。**

- **身体接触**：拥抱、击掌、握手等，建立安全感和亲密度。
- **日常操作**：让孩子在生活中"动手"——掂量白菜感受轻重、摸不同材质的衣物感受软硬、触碰水杯感受冷热。在真实操作中积累对物理世界的感知。

> **核心原则**：父母不是老师，应该少说教、少指导、少干预。

## 5W1H 总览

### Why（为什么要激活）

2-5 岁是大脑窗口期：0-3 岁神经元布线高峰，4-7 岁巩固整合。在此时通过听觉、视觉、触觉三条通路激活数感、空间感、逻辑感、抽象感，让孩子对数学信息建立"身体记忆"（手掂过轻重、眼看过多少、身体比过高矮），而非纯粹依赖符号记忆。没有早期激活不会怎样，但有激活的孩子在未来遇到分数、比例、概率等抽象概念时，理解速度会有显著差异——因为他们的大脑里已有现成的处理网络。

### What（做什么）

三件事并行：

1. **环境改造**（基础设施）：听觉三不、视觉精简+大字墙、触觉日常化
2. **结构化游戏**（有保证的刺激暴露）：积木排队站、积木拼拼看、彩纸回家、点数猜一猜
3. **家长行为改变**（底层操作系统）：从教师变为示范者，从评价者变为观察者

### Who（谁来做）

- **主导者**：与孩子相处时间最多的家长
- **配合者**：家庭所有成员（需同步"三不原则"，否则一人的克制会被另一人的催促抵消）
- **对象**：2-5 岁儿童
- **注意**：如祖辈是主要照顾者，需开一次家庭会议传达核心理念——不要求他们执行游戏，但要求他们不破坏环境

### When（什么时候做）

- **环境改造**：一次性完成，日常维护
- **结构化游戏**：每周 2-3 次，每次 15-20 分钟（2-3 岁）到 30 分钟（4-5 岁），选孩子情绪平稳、不饿不困的时段
- **触觉体验**：融入日常生活，不需要单独时间
- **听觉练习**：每一句话都是练习机会

### Where（在哪里做）

- **主要场地**：家中（游戏垫/餐桌旁/墙面/厨房）
- **延伸场地**：超市、菜市场、公园、小区路面、快递站
- **关键原则**：在真实场景中渗透，而非只在"学习角落"

### How（怎么做）

```
第 1 周：听觉改造（最难的先做，改变说话习惯）+ 清理散落玩具
第 2 周：贴大字墙 + 玩具轮换机制启动
第 3 周：触觉场景融入日常生活
第 4 周起：引入结构化游戏，按孩子节奏推进，不赶进度
```

## 金字塔原理：核心逻辑

**顶层结论：激活数学基因不是做更多事，而是做对的事——设计一个让孩子自己发现数学的环境，然后管住自己不去"教"。**

```
                        激活数学基因
                              │
              ┌───────────────┼───────────────┐
              │               │               │
          环境设计          结构化游戏        家长克己
         (被动激活)        (主动刺激)       (不破坏)
              │               │               │
    ┌─────┼─────┐     ┌───┼───┐      ┌───┼───┐
   听  视  触     积 积 彩 点      不 不 不
   觉  觉  觉     木 木 纸 数      说 评 催
   三  精  日     排 拼 回 猜      教 价 促
   不  简  常     队 拼 家 一
          化     站 看    猜
```

## 分阶段概览（2-5 岁）

| 维度 | 2-3 岁 · 感官激活期 | 3-4 岁 · 符号萌芽期 | 4-5 岁 · 逻辑萌发期 |
|------|-------------------|-------------------|-------------------|
| **阶段特征** | 语言爆发，注意力 3-8 分钟，手部精细动作弱，自我意识萌芽 | 能说完整句子，对符号产生兴趣，能搭积木，注意力 10-15 分钟 | 能理解规则和输赢，喜欢问"为什么"，能讨论策略，注意力 15-25 分钟 |
| **核心目的** | 让视/听/触三个脑区同时激活并建立初步连接 | 从"感官感受数量"过渡到"符号代表数量" | 理解局部与全部、概率与不确定性、策略与推理 |
| **环境重点** | 触觉 > 视觉 > 听觉 | 三者平衡 | 听觉（语言复杂度升级）> 视觉 = 触觉 |
| **游戏方式** | 家长示范，孩子旁观；简化版游戏 | 孩子参与完整游戏；开始有输赢概念 | 游戏变体增加；孩子参与规则讨论 |
| **成功标准** | 孩子愿意看/摸/听就是成功 | 孩子自发清点、能用身体表示数量关系 | 孩子理解输赢逻辑、能讨论游戏策略 |
| **关键禁忌** | 不要因孩子不参与而焦虑 | 不要纠正清点错误 | 不要故意让孩子赢（他会察觉） |

## 可量化标准

### 家长行为指标（每日自评）

| 指标 | 达标线 | 测量方式 |
|------|--------|---------|
| 重复指令次数 | ≤ 3 次/天 | 晚间回忆记录 |
| 语速/音量失控 | ≤ 1 次/天 | 伴侣互查或录音 |
| "教学冲动"忍住次数 | ≥ 2 次/天（看到了但忍住没说） | 晚间 3 分钟自省 |
| 身体接触 | ≥ 3 次/天（拥抱/击掌/握手） | 睡前记录 |

### 环境指标（每周检查）

| 指标 | 达标线 | 测量方式 |
|------|--------|---------|
| 外面散落玩具 | ≤ 3 件 | 拍照检查 |
| 大字墙是否在位 | 是 | 目视 |
| 玩具轮换 | 每 2 周轮换 1 次 | 日历提醒 |
| 触觉体验安排 | ≥ 5 次/周 | 周追踪表打勾 |

### 孩子行为信号（观察，不考核）

以下信号说明方法在生效，**不需要主动测试**：

- 孩子在家长数积木时盯着看 → 视觉-听觉通路正在连接
- 孩子日常中自发数东西（台阶、苹果） → 清点意识已内化
- 孩子驻足看大字墙 → 对文字符号产生了亲切感
- 孩子用手掂东西、摸材质 → 触觉通路活跃
- 孩子在游戏中输了能接受（4 岁+） → 情绪调节和规则理解在发育
