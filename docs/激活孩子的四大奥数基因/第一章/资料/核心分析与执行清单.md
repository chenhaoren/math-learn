# 第一章 · 核心分析与执行清单

> 基于《大脑发育与家庭环境布局》笔记的完整执行规划

---

## 一、核心知识提取

| 模块 | 核心要点 |
|------|---------|
| **大脑发育观** | 不是灌输而是激活，三大通路：听觉、视觉、触觉 |
| **神经元原理** | 860亿神经元出生时已存在，需要外界刺激来建立连接 |
| **关键窗口期** | 0-3岁布线高峰期，4-7岁巩固整合期，用进废退 |
| **听觉环境** | 三不原则：不加快语速、不提高音量、不用重复用语 |
| **视觉环境** | 少玩具（专注力）+ 大字墙贴（文字亲切感） |
| **触觉环境** | 身体接触 + 生活中体验轻重/软硬/冷热等物理属性 |
| **父母角色** | 少说教、少指导、少干预 |

## 三、执行 Checklist

### ☐ 第一步：听觉环境改造（第 1 周优先）

| # | 任务 | 验收标准 |
|---|------|---------|
| 1 | 有意识地放慢语速（比平时慢30%） | 和伴侣互相验证一周 |
| 2 | 全天不提高音量说话 | 手机录音回放检查 |
| 3 | 同一件事准备 3 种不同说法 | 例：吃饭→"该补充能量了/小肚子饿了吗/饭菜想你了" |
| 4 | 减少重复指令和口头禅 | 记录一天内重复的话，逐条替换 |

### ☐ 第二步：视觉环境改造（第 2 周）

| # | 任务 | 验收标准 |
|---|------|---------|
| 1 | 清理散落玩具，只留 2-3 件在外面 | 拍照前后对比 |
| 2 | 其余玩具分类收纳，每两周轮换一批 | 日历设置提醒 |
| 3 | 打印 100 个大字贴满一面墙 | 覆盖至少 2m²，与孩子视线平齐 |
| 4 | 观察孩子是否会驻足看字，**绝不主动教** | 记录观察日志 |

### ☐ 第三步：触觉体验设计（第 3 周起持续）

| # | 任务 | 验收标准 |
|---|------|---------|
| 1 | 每天至少 3 次拥抱/击掌/握手 | 以孩子主动或接受为准 |
| 2 | 每周 2-3 次"掂量游戏"（轻重对比） | 孩子能说出"这个重/轻" |
| 3 | 拓展到：冷热、软硬、粗糙/光滑的对比体验 | 生活场景自然融入 |
| 4 | 让孩子参与拿取物品的家务（拿菜、递水果等） | 孩子在无催促下完成 |

### ☐ 第四步：习惯与原则内化（持续）

| # | 任务 | 验收标准 |
|---|------|---------|
| 1 | 每日自省：今天有没有说教/指导/过度干预 | 晚间 3 分钟回顾 |
| 2 | 观察孩子主动学习时刻（停留看字、专注玩玩具） | 记录在手机备忘录 |
| 3 | 每周复盘：三条通路各执行了几项 | 对照周追踪表打勾 |

## 四、侧重点说明

| 模块 | 侧重点 | 为什么重要 |
|------|--------|-----------|
| **听觉** | ⭐ **家长自我约束** | 最难做到，因为改变说话习惯需要持续觉察。三不原则中"不重复"是核心——扼杀主动探索的往往是重复指令带来的压迫感 |
| **视觉** | ⭐ **环境设计 + 放弃教学** | 大字墙贴的关键是"看见了但没人教"——孩子主动停下来看才会有亲切感。玩具轮换是为了培养深度专注而非浅层刺激 |
| **触觉** | ⭐ **生活即教育** | 不需要特殊教具，买菜做饭就是最好的触觉教室。家长容易忽略的是"让孩子自己感受"而非"告诉孩子答案" |
| **父母角色** | ⭐ **克制比行动更重要** | "少说教、少指导、少干预"是贯穿三者的底层原则。做得少比做得多更难 |

---

## 五、建议执行节奏

```
第 1 周：听觉改造（最难，优先开始）+ 清理玩具
第 2 周：打印贴好大字墙 + 引入玩具轮换机制
第 3 周：设计生活中的触觉体验场景
持续：每日自省 + 每周复盘
```
