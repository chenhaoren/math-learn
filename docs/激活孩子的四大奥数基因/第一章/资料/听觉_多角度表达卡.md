# 听觉环境 · 多角度表达卡

> 核心原则：同一件事不重复说同一句话。
> 准备不同角度的表达方式，避免孩子因重复用语而感到压迫。
> 以下为 12 个日常高频场景的替换表达。

---

## 场景 1：吃饭

| 类型 | 表达 |
|------|------|
| ❌ 重复 | "来吃饭了！快点来吃饭！" |
| ✅ 能量角度 | "该补充能量啦～" |
| ✅ 嗅觉角度 | "闻闻今天锅里飘的什么香？" |
| ✅ 好奇心角度 | "猜猜今天餐桌上有什么颜色的菜？" |
| ✅ 角色感角度 | "小厨师上桌啦！" |

---

## 场景 12：主动学习时刻

| 类型 | 表达 |
|------|------|
| ❌ 重复 | "宝宝真棒！（每次都说同一句）" |
| ✅ 具体描述 | "你自己停下来看那个字看了好久呢" |
| ✅ 感受确认 | "你看得很认真，是不是觉得那个字的样子很有趣？" |
| ✅ 开放式终结 | "如果你想知道它念什么，随时可以来问妈妈" |

---

## 使用提示

1. **先备后用**：每天选 2-3 个场景，提前看一遍对应表达
2. **语气比内容更重要**：保持平静、温和的语速
3. **允许沉默**：说完一句后，给孩子 5-10 秒回应时间
4. **失败了也没关系**：偶尔说了重复的话，下次注意到就好
