# 激活孩子的四大奥数基因

> **让孩子像数学家一样思考**

## 关于本书

本书从大脑发育的底层规律出发，提出"激活而非灌输"的核心理念，通过**听觉、视觉、触觉**三大通路，全面激活孩子的数学思维基因：

- **数感** — 对数字和数量的直觉
- **空间感** — 对形状、位置和空间的感知
- **逻辑感** — 对因果关系和推理的把握
- **抽象感** — 从具体到抽象的思维能力
